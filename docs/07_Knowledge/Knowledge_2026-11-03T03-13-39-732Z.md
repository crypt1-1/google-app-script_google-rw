# Knowledge Summary

ステップ 1：定期実行用の関数を GAS に追加する
GASエディタの grw.gs（または適当な .gs ファイル）の下部に、引数を取らない（括弧の中が空の） 定期実行用の専用関数を追加して保存します。

以下のコードを貼り付けてください。

JavaScript
/**
 * 定期実行用エントリーポイント（引数なし）
 * 設定したスケジュール（毎日・毎時など）に従って自動で呼び出されます。
 */
function runScheduledTask() {
  try {
    Logger.log('=== 定期実行タスクを開始します ===');
    
    // 1. 10個の Drive フォルダ構造の自動アサート（整合性チェック）
    Object.keys(DRIVE_STRUCTURE).forEach(key => {
      assertAndGetFolder_(DRIVE_STRUCTURE[key]);
    });
    Logger.log('すべての Drive フォルダ構造（10箇所）の整合性確認（アサート）が完了しました。');
    
    // 2. 自動巡回タスクの生成（09_Tasks へ保存 ＆ 原本パス埋め込み）
    const today = new Date().toISOString().split('T')[0];
    const taskTitle = `自動定期巡回レポート_${today}`;
    const taskContent = '日次システム巡回および Drive フォルダ構造の整合性自動アサートが正常に完了しました。';
    
    // 既存のタスク作成関数を呼び出して保存
    const result = createAndSaveTask(taskTitle, taskContent);
    
    if (result.success) {
      Logger.log('定期タスクの自動保存に成功しました: ' + result.fileUrl);
    } else {
      Logger.log('定期タスクの保存に失敗しました: ' + result.message);
    }
    
    Logger.log('=== 定期実行タスクが正常に終了しました ===');
  } catch (e) {
    Logger.log('【エラー】定期実行タスクで例外が発生しました: ' + e.message);
    // 必要に応じてエラー時の通知処理などをここに追加できます
  }
}
ステップ 2：コードを保存する
GASエディタ上のフロッピーディスク（保存）アイコン、または Ctrl + S（Macは Cmd + S）を押して、コードを保存します。

ステップ 3：トリガーを設定する（自動化の有効化）
先ほどお送りいただいた設定画面の画像に沿って、以下の手順でトリガーを紐付けます。

トリガー画面を開く

GASエディタの左側メニューにある 時計マーク（トリガー） をクリックします。

トリガーの追加

画面右下にある 「＋ トリガーを追加」 ボタンをクリックします。

各項目の設定

実行する関数を選択: リストから今回作成した runScheduledTask を選択します（※引数なしの関数なので、ここで正しく選べます）。

実行するデプロイを選択: そのまま Head （最新のコード）を選択します。

イベントのソースを選択: 時間主導型 を選択します。

時間ベースのタイマーのタイプを選択:

例：毎日自動実行したい場合は 日付ベースのタイマー を選択します。

時刻を選択:

例：午後 8 時～9 時 など、実行したい時間帯を選択します。

保存する

右下の 「保存」 ボタンをクリックします。

初回のみ、Googleアカウントの「権限の承認（アクセス許可）」画面が表示されるため、指示に従って許可を進めてください。
